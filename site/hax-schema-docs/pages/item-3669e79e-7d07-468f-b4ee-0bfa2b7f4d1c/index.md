Settings provide the editing form fields the user sees. This is a simplified version of JSON Schema and supports `property`, `attribute`, or `slot` as far as what it is mapped to. `title` and `description` are shown to the user on the form while `inputMethod` determines the control rendered.

Settings has 3 possible properties which hold an array of fields to generate. `configure`, `advanced`, and `developer` correspond to the collapsed areas in the editing form.
